# AiTextApp_iOS

X（旧Twitter）のタイムラインのように短いテキストを扱う、iOS向けメモアプリのリポジトリです。

> **現在の状態:** アプリケーションコードやXcodeプロジェクトはまだ登録されておらず、構想・初期準備段階です。現状の詳細は [`CURRENT.md`](CURRENT.md) を参照してください。
