# Session Records

AIエージェントの調査・変更・検証を、次の担当者が短時間で引き継ぐための記録です。長大な会話ログやコマンド出力は保存しません。

ファイル名は `YYYY-MM-DD-short-topic.md` を基本とし、同日の重複時は短い識別子を加えます。

```markdown
# Session: Short topic

- Date: YYYY-MM-DD

## Request
依頼の要約。

## Investigation
確認した入口、検索語、判明した事実。

## Changes
変更の要約。

## Files Changed
主要ファイル。

## Validation
実行コマンドと結果。未実行なら理由。

## Result
完了状態。

## Remaining Issues
未確認事項と次の候補。なければ「なし」。
```
